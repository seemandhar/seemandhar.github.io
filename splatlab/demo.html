    07 Falsification gauntlet

    12 The pipeline novelties

    14 contributions that make a 24-hour autonomous lab actually work.

    C1 · headlineorchestrator
    First end-to-end autonomous 3DGS pipeline
    Unifies whole-codebase evolutionary search, cross-pair verbal learning, adversarial falsification as a fitness signal, and an outer re-ideation feedback loop — all under a single master.
    C2 · evolvesplatify/evolve_blocks.py
    9-hook EVOLVE-BLOCK mapping
    Domain mapping from AlphaEvolve's generic markers to the 9 canonical 3DGS extension hooks. Every hook becomes an independently evolvable code region with guaranteed isolation.
    C3 · searchsplatify/eoh.py
    EoH × Elo × verbal gradients
    Hybrid evolutionary algorithm: EoH rationale-implementation pairs (5 operators, ε-greedy bandit) + ReEvo-style verbal gradients restricted to surprising-loss pairs + per-hook lesson grouping.
    C4 · safetysplatify/falsify.py
    Falsification as fitness signal
    3 attacks per S3 winner — edge scene, sparse-view, hparam-ablation. Failed attacks subtract 30 Elo. Hparam-crash = PASS (load-bearing). The search literally cannot drift into brittle solutions.
    §6 · costsplatify/cascade.py
    AlphaEvolve evaluation cascade
    S1 compile → S2 smoke → S3 single-scene → S4 full benchmark, with baseline-Δ gating. Turns a 150-GPU-day exhaustive search into a single GPU-day funnel.
    §7 · loopsplatify/evolution.py
    Outer re-ideation feedback
    When a generation plateaus below baseline, a fresh negative-aware ideator re-seeds at a higher abstraction level — never just re-mutates a doomed seed.
    §11 · masterautoresearch/supervisor.py
    Tick-based persistent orchestrator
    Each tick is a bounded ~40-turn Opus session that reads the ledger, decides, exits. State persists on disk so SIGKILL → resume at any tick boundary loses zero decision history.
    §12 · portevolve_block_mapper
    Cross-codebase auto-mapping
    Opus subagent reads any cloned 3DGS repo, identifies analogues of the 9 splatify hooks via AST + LLM reasoning. ≥5 hits → Track A. Otherwise Track B (freeform diffs).
    §14 · trustpaper_verifier
    Verification-gated writing
    Every numerical claim must trace to a ledger entry. paper.open_issues == [] is a hard precondition for stopping. The system literally cannot ship a paper that says something it didn't measure.
    U5 · gateidea_validator
    Pre-train idea scoring
    Opus agent scores ideas 0-10 on (literature precedent, hook availability, hook saturation, orthogonality). Bare hparam tweaks cap at 3.0 — never reach the trainer pool.
    U12 · rigornoise_floor
    Noise-floor before any winner
    3-seed baseline measures σ before any candidate is called a winner. Deltas smaller than 2σ do not count. Kills the "+0.08 dB!" false-positive trap.
    U16 · learncategory_stats
    Per-hook category learning
    Hooks with tried ≥5 ∧ wins == 0 auto-saturate. Ideator is forbidden to propose ideas against them — kills the "27 loss tweaks, 0 wins" pattern.
    C8 · BFTStree_search.py
    Best-first tree search over experiments
    Sakana-v2-style priority queue with 3DGS-specific scoring: 1.0·smoke_Δ + 0.6·novelty − 0.15·depth − 0.02·spent − 10 if debug_attempts ≥ 2. Frontier early-stop halts when nothing is promising.
    C9 · costbudget.py
    Hard $ budget per phase + per agent
    Per-phase USD caps (research $15, ideate $10, experiment $120, ablate $30, write $25, review $20). SDK-enforced per-agent max_turns × max_budget — auto-terminates, not a soft prompt rule.
